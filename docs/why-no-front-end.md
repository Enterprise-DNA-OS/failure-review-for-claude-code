# Why no front end

The work is a repeatable review of failure records, actions and evidence. Ask your coding agent to read or change those records through one CLI. Branded HTML views are read-only snapshots and draft documents are working papers.

This base has no mobile data capture, offline synchronisation, live collaboration, diagrams or drag-and-drop editor. It is not a product release or safety certification system. Enterprise DNA can build an agreed screen and integrations into your own version. The database remains yours.
